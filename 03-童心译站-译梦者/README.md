# 童心译站——儿童情绪陪伴 Agent

童心译站是一款面向 3—8 岁儿童及其家长的情绪陪伴 Agent 概念验证 MVP。项目尝试将孩子当天难以完整表达的经历，转化为可看、可听、可共读的个性化绘本，并为家长提供简单、可执行的陪伴建议。

> 当前版本用于初赛概念验证，重点证明“输入经历 → 服务端处理 → 生成故事 → 阅读与朗读 → 家长建议”的最小闭环，不代表规划中的所有 Agent 能力均已完成。

## 当前可验证功能

- 儿童语音入口与文字输入界面；
- 绘本风格和朗读音色选择；
- 前端通过 `/api/generate` 调用服务端；
- 未配置模型时返回明确标注的本地演示故事；
- 配置阿里云百炼后尝试调用模型，并将模型文本放入演示绘本；
- 三页绘本翻页；
- 使用浏览器语音合成功能朗读当前页面；
- 最后一页展示家长回应、共读问题和后续行动建议；
- `GET /api/generate` 可检查服务状态和当前运行模式。

## MVP 能力边界

当前版本已经跑通交互闭环，但仍属于概念验证：

- “语音输入”按钮使用匿名示例经历，尚未接入真实录音和语音识别；
- 演示绘本插图复用项目内的原型素材，尚未接入图像生成模型；
- 百炼返回内容仅作为故事文本的一部分，尚未实现完整结构化 Agent 工作流；
- 家长中心、数据库、长期记忆、监护人身份验证和鸿蒙多设备协同尚未实现；
- 情绪内容只作为日常陪伴线索，不构成心理或医学诊断。

## 本地运行

### 1. 环境要求

- Node.js 20 或更高版本
- npm

### 2. 安装依赖

```bash
npm install
```

### 3. 可选：配置百炼

不配置百炼也可以运行，系统会进入“本地演示模式”。

如需尝试模型调用，将 `.env.example` 复制为 `.env.local`：

```env
DASHSCOPE_API_KEY=你的_API_KEY
BAILIAN_APP_ID=你的应用_ID
```

真实密钥只能保存在 `.env.local`，不得提交到公开仓库或比赛压缩包。

### 4. 启动开发环境

```bash
npm run dev
```

打开：<http://localhost:3000>

### 5. 验证服务状态

浏览器访问：<http://localhost:3000/api/generate>

返回结果中的 `mode`：

- `demo`：未配置百炼，使用本地演示故事；
- `bailian`：已检测到百炼环境变量，将尝试调用模型。

### 6. 生产构建

```bash
npm run build
npm run start
```

## 推荐演示步骤

1. 打开首页，点击话筒，使用匿名示例经历快速体验；
2. 等待服务端返回故事；
3. 在阅读页翻阅三页内容；
4. 点击“朗读本页”，验证浏览器朗读；
5. 翻到最后一页，查看家长陪伴建议；
6. 切换为文字输入，自定义一段 500 字以内的日常经历再次生成。

## 安全边界

童心译站用于儿童日常情绪表达与亲子陪伴支持，不替代心理咨询、医学诊断或专业治疗。演示时请使用匿名、虚构或经过脱敏的内容，不要输入儿童真实姓名、学校、住址和联系方式。

## 初赛源码说明

本仓库为“童心译站”初赛概念验证 MVP，已完成主要界面原型、前后端请求闭环、演示绘本阅读、浏览器朗读及家长陪伴建议展示。真实语音输入、完整 Agent 规划、多模态内容生成、授权记忆与鸿蒙全场景协同属于后续实现内容。
